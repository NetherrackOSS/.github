<p align="center"><b>Open source server software for Minecraft: Bedrock Edition written in Java</b></p>

NetherrackOSS is an open-source organization focused on building experimental, community-driven software for **Minecraft: Bedrock Edition**.

We're interested in server software, networking, protocol implementation, APIs, developer tools, and generally figuring out how Minecraft servers work from the ground up.

## 🚀 Our Projects

### 🧱 Netherrack

**An experimental Minecraft: Bedrock Edition server software written in Java.**

Netherrack is being built from scratch with the goal of creating an independent, lightweight, and extensible Bedrock server implementation.

The project is currently in early development, with work focused on networking, the Bedrock protocol, login handling, blocks, and the foundations required for a functional Minecraft server.

**Repository:** [Netherrack](https://github.com/NetherrackOSS/Netherrack)

> ⚠️ Netherrack is experimental software. Expect incomplete features, breaking changes, and occasional bugs.

## 🎯 What We Care About

NetherrackOSS projects are built around a few principles:

* **Open source** — Our projects should remain accessible to the community.
* **Experimentation** — We aren't afraid to try unconventional approaches.
* **Learning** — Understanding how things work is just as important as making them work.
* **Independence** — We aim to build our own implementations rather than simply copying existing software.
* **Community** — Contributions, ideas, testing, and feedback are welcome.
* **Compatibility** — Where practical, our software should work across different operating systems and environments.

## 🛠️ Technologies

Our projects primarily use:

* ☕ **Java**
* 📦 **Maven**
* 🟩 **Minecraft: Bedrock Edition**
* 🌐 **Bedrock networking & protocol technologies**
* 🔧 **CloudburstMC libraries and tooling**

The exact technology stack varies between projects.
